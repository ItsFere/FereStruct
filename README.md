# FereStruct

**FereStruct** — это GUI-приложение для быстрого создания структуры проектов (файлов и папок) в один клик.

## ✨ Возможности

- **Готовые пресеты**: Python (базовый/полный), Веб (простой/полный), Игровой (пиксель-арт), Data Science, Django, FastAPI.
- **Живой предпросмотр**: правая панель показывает структуру проекта в реальном времени по мере расстановки галочек.
- **Управление файлами**: после создания проекта можно переименовывать файлы и папки прямо из интерфейса (иконка ✏).
- **Кастомизация**: тёмная и светлая темы, градиентный интерфейс, кастомный шрифт.
- **Сохранение пресетов**: можно создавать свои собственные наборы файлов и папок.
